# EMMA
### Exponential Money Making Algorithms

**Python Algorithmic Trading & Market Analysis Project**

EMMA is a Python based algorithmic trading research project designed to analyze financial markets, evaluate trading opportunities, and test trading strategies using historical market data.

## Features
- Multi stock market scanning
- Technical analysis using EMA, RSI, and ATR
- Historical strategy backtesting
- Risk management and position sizing
- Trade logging and performance analysis
- Market data visualization

## Technology Stack
- Python
- Pandas
- NumPy
- yfinance
- Matplotlib
- Git and GitHub
